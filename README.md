### Selected projects

> Most of these live in private repositories — the course repos contain material authored by FEUP teaching staff alongside my project groups' work. Happy to walk through any of it in a call, or share access on request.

#### Java-- Compiler
`Java` · `ANTLR` · `Gradle` — group project

A complete compiler for a Java subset: grammar, symbol table, semantic analysis, an OLLIR intermediate representation, and Jasmin/JVM bytecode generation.

**My part:** symbol-table construction and type resolution; semantic checks for method calls, instantiation and static-vs-instance access; OLLIR generation for calls, constructor arguments and unary arithmetic; and the Jasmin backend's field declarations, visibility and initialisers.

#### Project & Task Management Web App
`PHP` · `Laravel` · `Blade` · `PostgreSQL` · `Tailwind` · `Docker` — group project

Multi-user project management application with role-based access, a documented OpenAPI surface and a seeded PostgreSQL schema.

**My part:** the full admin panel — user and project management, permissions, suspension and deletion; the Laravel authorisation policies across the application; task groups, lists, comments and task dependencies; sorting and search; and error/success handling.

#### Caves — terminal game
`Java` · `Lanterna` · `Gradle` · `JUnit 5` · `Mockito` · `jqwik` · `PIT` — built solo

A terminal-rendered game with a menu, scoring leaderboard and game-over flow, built on the Lanterna terminal UI library.

Tested with JUnit 5 and Mockito, property-based tests with jqwik, and mutation testing with PIT — the test setup is the part I'd point at first.

#### Route Planning
`C++` · `CMake` · `Doxygen` — pair project

Graph route planning over a road network: Dijkstra and its variants for fastest driving routes, restricted routes with excluded nodes and segments, combined driving-and-walking journeys, and an environmentally-friendly path mode. Fully Doxygen-documented.

#### Interactive 3D Scene
`JavaScript` · `WebGL` · `GLSL` — group project

Real-time rendered outdoor scene built directly on WebGL.

**My part:** the horse-drawn wagon — steering geometry, hitch pivot and wheels; shader-driven detail work; hay loading and stacking; first- and third-person cameras; and single-light-source scene illumination.

#### Minix 3 Device Drivers & Game

Low-level programming directly against Minix 3 kernel interfaces.

**My part:** mouse and timer interrupt handling; interrupt subscription logic; XPM sprite rendering with transparency; the entity system and scoring.

#### Parallel & Distributed Computing

Assignments on memory-hierarchy performance and parallel/distributed execution.
